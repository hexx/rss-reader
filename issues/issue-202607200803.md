# 課題解決プロンプト: 検索機能の削除

## 1. 役割定義 (Persona)
あなたは高度なソフトウェアエンジニアおよび問題解決のエキスパートです。以下のコンテキストとゴールを基に、正確かつ効率的な修正/実装を行ってください。

## 2. 背景・前提条件 (Context)
- **現状発生している問題**:
  RSSリーダー（`rss-reader`）において、記事一覧の「検索機能」が運用上まったく利用されていないため、コードを削除してシンプルにする。
  検索機能はバックエンド（API）には存在せず、**すべてクライアント側のローカル絞り込み**として実装されている。
  - 検索ボックス（UI）と「検索」ボタン
  - `searchQuery` ステートによる `articles` のクライアント側フィルタリング（`matchesSearch` / `includesQuery`）
  - 「検索中は『さらに読み込む』ボタンを隠す」ための `shouldShowLoadMore(hasMore, searchQuery)` の分岐
  - 検索結果 0 件時の空状態メッセージ
- **再現手順**:
  1. `npm run dev` で開発サーバーを起動
  2. ヘッダーに表示されている「記事を検索...」入力欄と「検索」ボタンを確認（現状、運用上は使われていない）
- **関連ファイル/コード**（以下のファイルから検索機能に関連するコードをすべて除去すること）:
  - `src/client/App.tsx`
    - L24: `lucide-react` からの `Search` インポート
    - L44-60: `includesQuery` 関数および `matchesSearch` 関数
    - L30: `articlePagination.js` からの `shouldShowLoadMore` インポート
    - L113: `const [searchQuery, setSearchQuery] = useState('');`
    - L204-206: `filteredArticles` の `useMemo`
    - L208-216: `handleLocalSearch` の `useCallback`
    - L219: `const showLoadMoreButton = shouldShowLoadMore(hasMore, searchQuery);`
    - L316-336: 検索 `<form>` ブロック（`<Search />` アイコン付き入力 + 「検索」ボタン）
    - L363-389: 空状態（`<Empty>`）ブロック内の `filteredArticles` 参照、`searchQuery` による条件分岐、および `<Search />` アイコン
  - `src/client/articlePagination.ts`
    - L36-38: `shouldShowLoadMore(hasMore: boolean, searchQuery: string)` 関数（検索中は `false` を返す仕様を含む）。検索を消すなら本関数は単なる `hasMore` のエイリアスとなるため、**関数ごと削除し、呼び出し側で `hasMore` を直接使う**こと。
  - `src/client/App.test.tsx`
    - L115-171: `it('filters articles by search query', ...)` テスト（検索ボックスへの入力・「検索」ボタンクリックを検証）を削除
  - `src/client/articlePagination.test.ts`
    - L4: `shouldShowLoadMore` のインポートを削除
    - L50-54: `it('shows load more only in the normal browsing state', ...)` テスト（`shouldShowLoadMore` の検索分岐を検証）を削除
  - ※ `dist/`、`dist-client/` はビルド成果物のため対象外（再ビルドで更新される）。`node_modules/` は対象外。

## 3. 解決すべきゴール (Goal & Objective)
- [ ] `src/client/App.tsx` から検索 UI（検索 `<form>` ブロック）を完全に削除する
- [ ] `searchQuery` / `setSearchQuery` ステート、`matchesSearch`、`includesQuery`、`handleLocalSearch`、`filteredArticles` をすべて削除し、記事一覧は `articles` を直接レンダリングするように変更する
- [ ] `shouldShowLoadMore` 関数を削除し、`showLoadMoreButton` を `hasMore` に置き換える（`articlePagination.ts` および `App.tsx` の import を整理）
- [ ] 空状態（`<Empty>`）のアイコン・メッセージから検索の文脈を排除する
  - アイコン: `<Search />` を非検索系のアイコン（例: `Inbox` / `FileQuestion`）へ置換し、`Search` の `lucide-react` インポートを完全に削除する（※`<Search />` は空状態の装飾アイコンとしても使われているため要注意）
  - タイトル/説明: `searchQuery.trim().length > 0` の分岐を削除し、以下のみにする
    - タイトル: `showAllSelected ? '記事がまだありません' : '選択したソースの記事がありません'`
    - 説明: `'RSSフィードを追加して記事を取得しましょう'`
- [ ] 関連するテスト（`App.test.tsx` の検索テスト、`articlePagination.test.ts` の `shouldShowLoadMore` テスト）を削除する
- [ ] 制約事項: 既存の「未読のみ」「ソース絞り込み」「並び替え」「さらに読み込む」「既読処理」などの他機能を壊さないこと。削除後も `npm test` および `npm run build` が通ること。

- `npm test` および `npm run build` の実行結果（成功であること）
