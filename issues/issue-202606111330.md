ユーザーが記事を読むかどうかの判断材料にするため、記事カード内に記事のURLを表示する修正を行ってください。

【対象ファイル: `src/client/components/ArticleCard.tsx`】
以下の要件を満たすようにURL表示を追加してください：

1. 表示位置:
   タイトルの下にある「メタ情報（バッジや日付のエリア）」のすぐ下、またはカード最下部の「記事を読む」リンクの横など、既存のレイアウトに馴染む自然な位置に `article.url` を表示してください。

2. スタイリングと省略処理:
   - URLは長くなることが多いため、Tailwind CSS の `truncate` クラスを使用して、スマホでもPCでも枠からはみ出さずに1行で省略（...）されるようにしてください。
   - テキストサイズは `text-xs`、色は `text-muted-foreground` などを適用し、メインのタイトルや要約の邪魔にならない、控えめで美しいデザインにしてください。
   - 必要に応じて、URLの横にリンクアイコン（Lucideの `Link` など）を小さく添えるとより視認性が高まります。
