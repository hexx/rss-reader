# 課題解決プロンプト: RSS Readerで通常URLからRSSフィードを自動検出できるようにする

## 1. 役割定義 (Persona)
あなたは高度なフルスタック・Webエンジニアです。本リポジトリのRSS Readerプロジェクトにおいて、ユーザーが入力した「通常のWebページURL（例: ブログトップページ）」からRSSフィードを自動検出する機能（RSS Auto-Discovery）を追加実装してください。

## 2. 背景・前提条件 (Context)
- **現状の問題**: 現在、RSS Readerでフィードを追加する際には、ユーザーが **RSSフィードのURL（例: `https://example.com/feed.xml`）** を直接入力する必要がある。
- **改善要望**: 通常のWebページのURL（例: ブログ・ニュースサイトのトップページ `https://example.com/`）を入力した場合でも、そのページが指し示しているRSS/Atomフィードを自動で探し出して登録できるようにしたい。
- **想定ユースケース**: ユーザーがブラウザのアドレスバーからそのままブログのURLをコピーして貼り付けた場合でも、内部の `<link rel="alternate" type="application/rss+xml" ...>` タグ等からフィードURLを検出し、シームレスに購読を開始できること。
- **前提条件**:
  - 既存の「RSSフィードURLを直接入力して追加する」フローは壊さない（後方互換）。
  - リポジトリ構成・既存コードのスタイル（フレームワーク、状態管理、エラーハンドリング、テスト方針）に従う。
  - 外部サービスへの過度な依存や、無断で情報を送信する挙動は禁止。

## 3. 解決すべきゴール (Goal & Objective)
- [ ] **RSS Auto-Discovery の実装**: 入力されたURLがRSSフィード（`application/rss+xml` / `application/atom+xml`）を示していない場合、そのURLのHTMLを取得し、`<link rel="alternate" type="application/rss+xml" ...>` および `<link rel="alternate" type="application/atom+xml" ...>` タグから `href` を抽出して、フィードURLとして採用する。
- [ ] **複数候補の優先順位付け**: 同一ページ内に複数のフィードが記載されている場合は、`type`、および可能であれば `rel="alternate"` 以外の `rel="self"` も考慮し、最も適切な1件（または限定数）を選択する。
- [ ] **既存入力との互換性**: 直接RSSフィードURLが入力された場合はこれまで通り即時追加できること（HTMLパースをスキップする）。
- [ ] **エラー時のユーザーフィードバック**: フィードが見つからない・HTMLが取得できない・タイムアウトする等の失敗時に、既存のトースト/エラー表示機構を用いて分かりやすく通知する。
- [ ] **テストの追加・更新**:
  - 通常URLからフィードが自動検出できるケースのユニット/統合テスト
  - RSSフィードURLを直接渡したときに既存通り動くテスト
  - フィードが見つからない場合の挙動テスト
- [ ] **ネットワークアクセスに関する注意**:
  - サーバーサイドでHTMLを取得する場合はSSRF対策（内部アドレス・localhost・メタデータIP等のブロック）を講じる
  - 適切な `User-Agent`、タイムアウト、リダイレクト上限を設定する
  - リダイレクトループを避ける

## 4. 期待する成果物 (Output Format)
- 修正/追加されたコード一式（コンポーネント、フック/アクション、サーバーAPI、ヘルパー等）
- 必要に応じて追加されたライブラリ（パース用: 例 `fast-xml-parser`, `cheerio`, `node-html-parser` など）と、その選定理由
- 変更・追加したファイル一覧とそれぞれの役割
- 既存テストが通ること、追加したテストが通ることの確認結果（テスト実行ログの要約）
- アプローチ解説（どこでHTML取得・パース・判定を行っているか、既存フローとの統合方法）

## 5. 実行開始の合図
このプロンプトを理解したら、「タスクを開始します」と宣言し、まずリポジトリ全体（パッケージ構成、既存フィード追加処理、テスト構成）を把握するところから着手してください。
