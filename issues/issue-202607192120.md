# 課題解決プロンプト: 本番のAI環境変数設定手順の明文化と、OpenAI/Anthropic互換プロバイダへの再検討

## 1. 役割定義 (Persona)
あなたは高度なソフトウェアエンジニアおよび問題解決のエキスパートです。以下のコンテキストとゴールを基に、正確かつ効率的な修正/実装を行ってください。

## 2. 背景・前提条件 (Context)
- **現状発生している問題**:
  - 本番環境（Cloudflare Workers）での `OPENCODE_GO_API_KEY` / `OPENCODE_GO_BASE_URL` / `OPENCODE_GO_MODEL` の設定方法が開発者にわからない。
  - `.env.example` には `OPENCODE_GO_BASE_URL=http://localhost:11434/v1` とあり、これはローカルの **Ollama**（デフォルトポート 11434）を指しており、本番向けの設定ではない。
  - 変数名・プロバイダ名が "opencode-go" となっているが、実体は `src/services/ai.ts` 内で `@ai-sdk/openai-compatible` の `createOpenAICompatible` を使っている**純粋な OpenAI 互換プロバイダ**である。そのため「OPENCODE_GO 専用」という印象は誤りで、実際には任意の OpenAI 互換エンドポイント（OpenAI 本家、各社ゲートウェイ、ローカルの Ollama 等）を指せる。
  - 開発者から「OpenCODE_GO じゃなくて OpenAI か Anthropic 互換 API で良いのではないか？」という疑問・再検討の要望が出ている（直感は正しい）。
- **再現手順**:
  - `cat .env.example` を確認するとローカル Ollama 向け設定しか書かれていない。
  - 本番デプロイ手順（環境変数/シークレットの注入方法）が README やドキュメントに存在しない。
- **関連ファイル/コード**:
  - `src/env.ts`（`RuntimeEnv` インターフェースで 3 変数を定義）
  - `src/services/ai.ts`（`createOpenCodeGoProvider` が `createOpenAICompatible` を使用）
  - `wrangler.toml`（Cloudflare Workers のバインディング/変数設定）
  - `.env.example`（ローカル開発用サンプル）
  - `README.md`（設定手順の記載先）
  - テスト: `src/services/ai.test.ts`, `src/worker.test.ts`

## 3. 解決すべきゴール (Goal & Objective)
- [ ] **本番設定手順の調査と文書化**: Cloudflare Workers において API キーなどのシークレットを `wrangler secret put`（非公開値）または `wrangler.toml` の `[vars]`（公開値・ベースURL・モデル名）で設定する正しい手順を確定し、README に記載する。
- [ ] **命名の再検討・リネーム提案**: "opencode-go" という名称が実態（OpenAI 互換）と乖離しているため、`OPENCODE_GO_*` を `AI_*` / `LLM_*` 等の汎用的な名前に変更するか、現状維持の場合はその理由と「OpenAI 互換エンドポイントなら何でも指定可」であることを明記する。
- [ ] **プロバイダ選定の判断**: OpenAI 互換エンドポイント（OpenAI 本家・各社ゲートウェイ）の利用をデフォルトとする。Anthropic も利用したい場合は、Anthropic は OpenAI 互換ではないため `@ai-sdk/anthropic` の追加、または OpenAI 互換ゲートウェイ経由（Anthropic を OpenAI 互換でプロキシ）のどちらが適切か判断・提案する。
- [ ] **サンプル・ドキュメントの更新**: `.env.example` のベースURLを本番/汎用向けに補足し、README に「プロバイダ選択のガイド（どのエンドポイントを BASE_URL に指定すればよいか）」を追記する。
- [ ] **制約事項**: 既存テスト（`src/services/ai.test.ts`, `src/worker.test.ts`）を壊さないこと。リネームを行う場合は該当箇所の一貫した修正と、必要に応じたテスト更新を行うこと。
