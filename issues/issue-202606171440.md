記事カード（ArticleCard）の下部にある「記事を読む」リンクの左隣に、はてなブックマークのコメントページへ遷移するための「コメントを読む」リンクを追加してください。

【対象ファイル: `src/client/components/ArticleCard.tsx`】
以下の要件を満たすように修正してください。

1. はてなブックマークURLの生成ロジックを追加:
   - ファイルの上部（コンポーネントの外）に、元のURLからはてなブックマークのエントリーページURLを生成する関数を追加してください。
   - 仕様: `https://` で始まるURLは `https://b.hatena.ne.jp/entry/s/` + ドメイン以降 に変換。`http://` で始まるURLは `https://b.hatena.ne.jp/entry/` + ドメイン以降 に変換します。
   - 実装例:
     ```typescript
     function getHatenaEntryUrl(url: string): string {
       return `https://b.hatena.ne.jp/entry/${url.replace(/^https:\/\//, 's/').replace(/^http:\/\//, '')}`;
     }
     ```

2. リンクの追加:
   - `<CardContent>` の一番下にある ` {/* Read article link */} ` の `div` コンテナを修正します。
   - `className="flex justify-end gap-4"` に変更して要素間を少し開けてください。
   - 「記事を読む」リンクの**左隣**に、「コメントを読む」リンクを追加してください。
   - アイコンにはすでにインポートされている `MessageSquare` (`lucide-react`) を使用してください。
   - リンクのクラスには `className="inline-flex items-center gap-1 text-sm text-muted-foreground hover:text-primary hover:underline"` を設定し、メインの「記事を読む」ボタンより少し控えめなデザインにしてください。
   - もちろん `target="_blank" rel="noreferrer noopener"` を付与してください。
