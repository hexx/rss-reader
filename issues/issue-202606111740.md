スマートフォン表示において、縦と横の「二重スクロール」が発生して操作性が著しく悪化している問題を修正してください。

【1. App.tsx: 縦の二重スクロール（100vh問題）の修正】
- スマホブラウザのアドレスバー高さを考慮するため、`src/client/App.tsx` のトップレベルのコンテナのクラスにある `h-screen` を `h-[100dvh]` に変更してください。
- 修正箇所: `<div className="flex h-screen flex-col w-full overflow-x-hidden">`
- 修正後: `<div className="flex h-[100dvh] flex-col w-full overflow-x-hidden">`

【2. ArticleCard.tsx: 横の二重スクロール（AI生成HTMLのはみ出し）の修正】
- AIが生成した要約（`<pre>`, `<table>`, 長いURLなど）がカードを押し広げないように、`src/client/components/ArticleCard.tsx` の要約表示部分にスクロールと縮小のロックをかけます。
- `article.summary` および `article.hatenaSummary` を表示している `dangerouslySetInnerHTML` を持つ `div` タグのクラスに、`overflow-x-auto` と `min-w-0` と `w-full` を追加してください。
- 修正例: `<div className="text-sm leading-relaxed overflow-wrap-anywhere overflow-x-auto min-w-0 w-full" dangerouslySetInnerHTML={{ __html: ... }} />`
- また、その2つの要約箱を囲んでいる親のグリッド `<div className="grid gap-3 sm:grid-cols-2">` にも `min-w-0` を追加して、グリッド自体が親（CardContent）を突き破らないようにしてください。

## 解決記録
- 2026-07-22: 監査で確定。h-[100dvh] + min-h-0 + overscroll-contain 適用済み。
